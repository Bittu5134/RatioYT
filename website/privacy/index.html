Privacy Policy

Overview

RatioYT is designed with privacy as a foundational principle. We believe browser extensions should respect user agency, minimise network footprints, and operate without tracking, analytics, or data harvesting.

  • Zero Telemetry & No Personal Data → RatioYT does not collect, log, store, or transmit any personally identifiable information, browsing history, keystrokes, mouse events, accounts, or analytics. There are no tracking scripts, third-party cookies, or analytics SDKs anywhere in the extension or userscript.
  • Network Requests → RatioYT makes outbound network requests exclusively to two public endpoints:

    (1) Return YouTube Dislike API (https://returnyoutubedislikeapi.com/) — Public queries containing only the YouTube video ID to fetch public like/dislike counts. No user accounts or personal metadata are attached to these calls.

    (2) RatioYT Config (https://ratioyt.bittu.dev/selectors.json) — Retrieves updated YouTube DOM selector strings to ensure badges continue displaying if YouTube alters its HTML markup. No user data is sent.
  • On-Device Local Storage → Ratings are cached locally in your browser's IndexedDB for up to 7 days so repeated video views skip the network entirely. Display preferences (format, color, score threshold, filter-only mode) are saved strictly inside your browser's local extension storage.
  • No Data Sharing or Monetisation → We do not sell, rent, trade, or transfer any user data to any third parties. We do not use data to profile users, determine creditworthiness, serve ads, or engage in lending.
  • Open Source & Auditable → RatioYT is 100% free software licensed under GPL-3.0-or-later. The complete source code is public and fully auditable on GitHub.

Questions & Contact

If you have questions about this Privacy Policy or wish to report an issue, feel free to open a ticket on GitHub Issues or reach out directly at hello@bittu.dev.
