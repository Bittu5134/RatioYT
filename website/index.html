A lightweight browser extension that rates YouTube videos and filters low-rated videos.

Pick your browser. Source builds are available on GitHub Releases.

Features & How It Works

  • Like/dislike ratios on videos → Shows a score on video cards on Home, Search, Shorts, and recommendations. Scores come from the Return YouTube Dislike (RYD) service, not YouTube, so they can occasionally be missing or delayed.
  • Pick your format → Display scores as a percentage (96%), a rating out of 10 (9.6/10), smiley emojis (😊 😐 😞), or 5-star SVGs with half stars.
  • Optional colour tint → Shades each score badge from red to green based on its rating, making low and high scores easy to spot.
  • Hide low-rated videos → Replaces videos below a threshold you set (for example 25% or 40%) with an empty dark placeholder so you don't see clickbait or autostart previews.
  • Filter Only Mode → Hides the score badges from the feed while keeping low-rated video filtering active.
  • Local on-device cache → Stores scores in your browser's IndexedDB for 7 days so the same video isn't queried again every time you scroll or navigate.
  • Remote selector updates → When YouTube tweaks its page layout, the extension pulls updated selector rules from GitHub without waiting for a browser store release.
  • What it connects to → Only the public Return YouTube Dislike API (to look up ratings by video ID) and GitHub raw (to check for selector updates). Zero tracking, and the code is open source under GPL-3.0.
