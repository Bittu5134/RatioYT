A lightweight browser extension that brings like/dislike ratios back to YouTube video cards and filters low-rated videos.

Note: RatioYT is available across all major Chromium and Gecko browsers. Source builds are available on GitHub Releases.

Features & How It Works

  • Score Badges → Displays authentic like/dislike ratios on video cards across Home, Search, Shorts, and watch suggestions.
  • Score Source → Scores come from the public Return YouTube Dislike API database.
  • Four Display Formats → Choose between Percentage (96%), 10-point decimal (9.6/10), Smiley emojis (😊 😐 😞), or 5-star SVGs with half stars.
  • Dynamic Colours → Optional red-to-green score colouring so high-quality content and clickbait are obvious at a glance.
  • Filtered Placeholders → Videos below your custom score threshold are replaced in-place with dark placeholders, stopping video previews and audio.
  • Quiet Mode → Hides all score badges for a clean feed while continuing to filter low-rated videos quietly in the background.
  • On-Device Cache → Lookups are cached on your machine in IndexedDB for 7 days; repeat views take zero network requests and render instantly.
  • Remote Selectors → YouTube UI layout updates are handled automatically via remote selector syncing without waiting for a store release.
  • Zero Telemetry → Zero trackers, zero analytics, zero data collection. Only contacts the public Return YouTube Dislike API.
